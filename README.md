# My Kitty Terminal Configuration
[Download Kitty Here (not available on native Windows, need to use WSL2)](https://sw.kovidgoyal.net/kitty/binary/)

## Requirements
- Nerd Font, choose one to use (Install bold, italic, and regular):
    - JetBrainsMono
    - FiraCode
    - 0xProto
- Git

The config uses the JetBrainsMono nerd font but you can change the font without touching the config by running this command
`kitten choose-fonts`

Make sure the font you want to change to is installed.

After installing Kitty, run the following command: 
`git clone git@github.com:swampPr/kitty-conf.git ~/.config/kitty/`

and thats it.
